# Pembagian Tugas (3 Orang) — Sprint 5x5 Hari

| Sprint | Hari | Orang A (Customer) | Orang B (Admin) | Orang C (Driver/Worker) |
|--------|------|--------------------|-----------------|--------------------------|
| **1** | 1-5 | Landing page + Auth (login, register, middleware) + Navbar + Footer | Admin authorization + CRUD user (outlet admin, worker, driver) + tabel user | Attendance (absen, history, report) |
| **2** | 6-10 | Verifikasi email + set password + reset password + profile (edit, upload foto) | Outlet management (CRUD outlet, assign user ke outlet) + map leaflet | Driver management (list request, notifikasi real-time, proses pickup/delivery, hanya 1 order aktif) |
| **3** | 11-15 | Manajemen alamat (CRUD, set main) | Order management (lihat semua order, filter per outlet/status/tanggal, tracking) | Worker management (notifikasi, daftar pesanan di station) |
| **4** | 16-20 | Request pickup (pilih alamat & jadwal, cari outlet terdekat, assign ke driver) | Create order dari pickup request (input kg & item) + bypass process (approve/reject with PIN) | Worker processing (input ulang quantity, validasi mismatch, request bypass) |
| **5** | 21-25 | Tracking order + payment gateway (Midtrans) + konfirmasi otomatis | Report & analysis (sales per hari/bulan/tahun, performa karyawan, export PDF/CSV) | Packing station (cek payment, ubah status) + auto trigger delivery request + job history |

📋 Catatan Teknis

⚡ Shift Guard — assertShiftEligibility()

Beberapa endpoint driver/worker menerapkan business guard yang mengembalikan 403 ketika:

  • Shift tidak sedang aktif (di luar jam shift terdaftar)
  • Karyawan belum check-in hari ini
  • Karyawan sudah check-out

Endpoint yang terpengaruh: GET /driver/pickups/available, GET /driver/deliveries/available, GET /worker/station/:station, POST .../submit-items, PATCH .../complete

🔢 Kode Status Validasi

API menggunakan 422 Unprocessable Entity (bukan 400) untuk error validasi Zod. Test menerima keduanya: [400, 422].

📦 Response Shape Endpoint

  • Customer endpoints (apiResponse.ok()): { success, message, data: [...] }
  • Admin list endpoints (spread result): { success, items: [...], pagination: {...} }
  • Customer profile: raw res.json(profile) — langsung cek res.body.email
  • DELETE address: HTTP 204 No Content (bukan 200)

🗃️ Database & Cleanup

Tests berjalan terhadap Neon production DB (serial, maxWorkers: 1). Setiap test membuat data unik (${'$'}{Date.now()}) dan membersihkannya di afterAll. Tidak ada data test yang tersisa setelah run.
